# Source notes

These are deterministic rules distilled from the PDFs supplied by the user in the earlier MarketPulse work.

## D-Line
15m/1h execution, preferably about three trend-line touches, trend geometry/angle, larger-trend context, body-close confirmation, breakout/retest entries, source checklist RR 2:1+ and 0.618/local-origin profit references.

## Bitcoin price action
Weekly open and previous weekly high/low form key higher-timeframe context. SFP requires a sweep and a close back inside the prior range. A close beyond the level is treated as breakout, not SFP. MSS/MSB needs structural close confirmation and breakout filtering.

## Advanced order flow
Track buy-side/sell-side liquidity, premium/discount context, CVD from taker-side trades, OI changes, FVGs, order blocks and breakers. The source guide specifies a strict 1:3 technical RR; the engine defaults to 3:1.

These are educational source-derived rules, not a guarantee of profitability.
